Sobre

De campo pra base de dados

Trabalho como técnico de instalação de fibra óptica na Icomon/Vivo, resolvendo problemas de infraestrutura que não têm margem pra erro: um ponto de falha e o cliente fica sem conexão. Foi ali que percebi que já pensava como alguém de dados — mapeando sistemas, rastreando falhas na origem, documentando cada porta e cada caminho.

Hoje estou formalizando isso: sou formado em Análise e Desenvolvimento de Sistemas e curso MBA em Data & Analytics na Mackenzie. Construí pipelines reais, do dado bruto ao dashboard, e sigo um plano estruturado de 6 meses pra entrar no mercado como engenheiro de dados júnior.

Não é uma troca de área do zero — é continuar fazendo infraestrutura funcionar, só que agora o sinal que precisa chegar limpo é o dado.

Portfólio

pipeline_financeiro

ETL · PostgreSQL · Python

Pipeline completo de ETL processando transações financeiras reais (dataset Kaggle): extração e transformação em Pandas, carga em PostgreSQL 18, SQL avançado com CTEs e window functions, variáveis de ambiente seguras com python-dotenv, logging profissional, 5 testes automatizados com pytest e dashboard final em Power BI Desktop.

github.com/alexvini-data/pipeline-financeiro ↗

hr-attrition-ml

Machine Learning · Databricks

Pipeline de Machine Learning completo para prever rotatividade de funcionários (projeto de MBA): construído no Databricks, com balanceamento via SMOTE, modelo LightGBM, interpretabilidade com SHAP e ensemble por Voting Classifier.

github.com/alexvini-data/hr-attrition-ml ↗

mapeamento_portas — em construção

PostgreSQL · Modelagem de dados

Sistema de mapeamento de portas de fibra óptica nascido de um problema real do meu dia a dia como técnico. Schema PostgreSQL com triggers de aprovação hierárquica, histórico de auditoria e controle de concorrência — documentado com ERD em Mermaid e DBML.
